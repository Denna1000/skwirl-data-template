# skwirl-data-template

Lege startversie van de gegevens voor [Skwirl](https://denna1000.github.io/skwirl/): een gedeeld boodschappenlijstje met je vaste producten en hun aanbiedingen.

**Begin hier: [HANDLEIDING.md](HANDLEIDING.md)** (stap voor stap, ongeveer 30 minuten).

Kort: klik op **Use this template**, noem je kopie `skwirl-data` en maak hem **Private**. Er staan geen persoonlijke gegevens in deze startversie.

| Bestand | Inhoud |
|---|---|
| `list.json`, `household.json` | jouw lijst, adressen, winkels en vaste producten (de app vult ze) |
| `deals.json` | aanbiedingen (de scan vult ze) |
| `SCAN.md` | de opdracht voor Claude |
| `.github/workflows/aanbiedingen.yml` | de scan op GitHub |
| `scripts/` | ophalen, snel koppelen, opslaan, en de Mac als bron |
